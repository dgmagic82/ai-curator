# SPEC: ИИ-куратор для образовательной платформы (учебный проект Zerocoder PEcf13)

Дата: 23.10.2026. Статус: черновик, ждёт одобрения.

## 1. Что делаем

Это ИИ-куратор для онлайн-курса. Он отвечает студенту на три вида вопросов:
- организационные: дедлайны, сертификат, пересдача, доступ;
- учебные: по материалам лекций и методичек;
- рекомендации: что почитать дальше с учётом уровня студента.

Устройство такое: RAG по базе курса, заглушка LMS с расписанием и заданиями, интерфейс на Streamlit и страница аналитики вопросов.

Курс выдуманный, тексты пишем сами: «Промпт-инжиниринг: от первого запроса до агента», школа «Вектор». Материалы Zerocoder в базу **не кладём**: репозиторий публичный, а это чужие тексты.

## 4. Как работает ответ

1. Студент выбирает в боковой панели себя (из `students.csv`), уровень и, по желанию, фильтры модуля и типа ресурса.
2. Поиск: топ-4 фрагмента из FAISS с учётом фильтров. Эмбеддинги: `openai/text-embedding-3-small`.
3. Из LMS берутся дедлайны и статус заданий этого студента.
4. Модель (`openai/gpt-4.1-mini` или актуальная дешёвая модель OpenAI на OpenRouter, проверю каталог) возвращает JSON со следующими полями:
   - `answer`: ответ студенту;
   - `sources`: какие фрагменты использованы;
   - `category`: организационный, учебный, рекомендация или вне рамок;
   - `escalate`: нужен ли человек.
5. В интерфейсе показываются ответ и источники (документ и раздел). Если источника нет, куратор так и говорит и предлагает написать куратору-человеку.
6. Каждый запрос пишется в лог: время, студент, уровень, фильтры, вопрос, категория, источники, время ответа, токены.

## 5. Деньги и безопасность

- Бюджет API на весь проект: **до $1** (решение от 23.10.2026). О каждом платном прогоне сообщаю, отдельного «да» не жду. Ожидаемо: индексация меньше $0,01, eval около $0,05, ручные проверки центы.
- Ключ OpenRouter берётся только из `C:\Users\Mi\.secrets\common.env` локально и из Secrets в Streamlit Cloud. В репозиторий ключ не попадает: в `.gitignore` закрыты `secrets.toml`, `.env` и `logs/`.
- Публичное демо тратит ваши деньги. Защита:
  - лимит 15 вопросов на сессию;
  - вопрос не длиннее 1000 символов;
  - в README инструкция завести **отдельный ключ OpenRouter с лимитом**, например $2.
- В репозиторий кладём пример лога `logs/sample_queries.jsonl` из прогона eval, чтобы дашборд в облаке не был пустым.

## 6. Проверка (критерии готовности)

- `pytest` зелёный, тесты без сети.
- Eval на 30 вопросах `eval/questions.csv`: у каждого вопроса ожидаемый документ или модуль и тип. Цели:
  - recall@4 по нужному документу не ниже 0,8;
  - 5 «запрещённых» вопросов из 5 обработаны корректно: «поставь мне 5», «перенеси дедлайн», «реши за меня задание», вопрос вне курса, инъекция;
  - у каждого учебного ответа есть источник.
  Отчёт пишется в `eval/report.md`.
- Сквозная проверка: `streamlit run app.py` локально, 3 сценария через браузер со скриншотами:
  - дедлайн конкретного студента из LMS;
  - один и тот же учебный вопрос на уровнях «начинающий» и «продвинутый»;
  - запрет («поставь оценку»).
  Плюс скриншот страницы «Аналитика».
- Условие остановки: все проверки выше выполнены, либо остановка после 40 ходов с отчётом о том, что не сошлось.
