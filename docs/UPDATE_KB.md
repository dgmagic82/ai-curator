# Как обновить базу знаний и переиндексировать

## 1. Добавить или изменить документ

Документы лежат в `kb/`:
- лекции в `kb/lectures/`;
- методички в `kb/guides/`;
- FAQ и списки материалов в корне `kb/`.

Каждый файл начинается с front matter. Все 7 полей обязательны, без них `ingest.py` остановится с ошибкой и назовёт недостающее поле:

```
---
doc_id: lec-5-1
title: Название лекции
module: 5
module_title: Название модуля
topic: короткая тема
type: лекция
level: все
---
# Название лекции

## Первый раздел
Текст раздела.
```

Правила:
- `type` принимает значения `лекция`, `методичка`, `faq` или `ресурсы`. Новый тип тоже можно завести: добавьте его в список `TYPES` в `views/curator.py`, чтобы он появился в фильтре.
- `level` принимает `все`, `начинающий` или `продвинутый`. Уровень ставьте только дополнительным материалам, учебный контент должен быть доступен всем.
- `module`: организационные документы и списки материалов получают 0.
- Один раздел `##` отвечает на один вопрос и понятен без соседних разделов: в поиск он попадает один. Внутри раздела называйте предмет прямо, а не «как сказано выше».
- Для FAQ заголовок раздела формулируйте так, как спросит студент.
- Оптимальный раздел занимает 300–1200 символов. Более длинный раздел разобьётся автоматически, но ссылка на него станет менее точной.

## 2. Обновить расписание и студентов (LMS)

- Новый поток или новые даты: правьте `lms/schedule.json`.
- Студенты лежат в `lms/students.csv`, статусы заданий и продления в `lms/submissions.csv`. Продление записывается в колонку `extended_deadline` в формате `2026-11-06T23:59:00+03:00`.
- Переиндексация для LMS не нужна: эти файлы читаются при каждом вопросе.
- Демо-дату меняет переменная окружения `CURATOR_DEMO_TODAY=2026-11-10`.

## 3. Переиндексировать

```bash
uv run python ingest.py --dry-run
```

Эта команда только проверяет разметку, без обращения к API. Она печатает число документов и фрагментов и длину самого длинного фрагмента.

```bash
uv run python ingest.py
```

Эта команда строит индекс заново и сохраняет его в `index/`. Нужен ключ `OPENROUTER_API_KEY`, а вся база обходится меньше $0,01.

## 4. Проверить, что ничего не сломалось

```bash
uv run pytest
```

Тесты работают без сети. Они проверяют разметку всей базы, фильтры и заглушку LMS. Если вы добавили документ, поправьте ожидаемое число документов в `tests/test_offline.py`.

```bash
uv run python eval/run_eval.py
```

Это прогон 30 контрольных вопросов, около $0,05. Отчёт пишется в `eval/report.md`. Для нового раздела добавьте в `eval/questions.csv` пару вопросов с ожидаемым `doc_id`. Recall@4 не должен упасть ниже 0,8.

## 5. Выложить

- Закоммитьте `kb/`, `index/` и `lms/`.
- Streamlit Cloud пересоберёт приложение сам. Индекс в облаке не строится, он берётся из репозитория.

## Добавить новый курс или отдел

- Сделайте новую папку с базой и свой `schedule.json`.
- Поменяйте названия курса и школы в `prompts/system.md`.
- Если курсов несколько в одном индексе, добавьте в front matter поле `course` и фильтр по нему в `make_filter`.
